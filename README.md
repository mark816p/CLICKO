## 🚀 Overview

CLICKO was created to provide a modern, ultra-optimized alternative to basic click trackers (such as [Jeanp78/click-counter](https://github.com/Jeanp78/click-counter)). 

While standard click counters rely on high-level hooks that cannot identify the input source, **CLICKO taps directly into the Windows Raw Input API and PnP Device Tree**, allowing it to definitively report whether a click came from an external **USB Mouse** or a laptop's **Internal Touchpad**.

### 📊 Comparison: CLICKO vs. Traditional Click Counters

| Feature | CLICKO | Traditional / Python Click Counters |
| :--- | :--- | :--- |
| **Executable Size** | **~46 KB** (Single standalone `.exe`) | ~25 MB - 50 MB (PyInstaller bundles) |
| **RAM Footprint** | **~12 - 15 MB** | ~50 - 90 MB |
| **Idle CPU Usage** | **0.00%** (Hardware event-driven) | Often 0.5% - 2.0% polling overhead |
| **Hardware Detection** | **Yes**: USB Mouse vs. Touchpad | ❌ Not possible with `WH_MOUSE_LL` hooks |
| **Disk I/O** | **Smart Flush**: Debounced 5s atomic save | ⚠️ High disk wear: writes on *every single click* |
| **Startup Integration** | **1-Click Built-in Toggle** | Manual folder creation / shortcut placement |
| **User Interface** | **Dark Fluent Dashboard + Tray** | Tooltip only |
| **Dependencies** | **Zero** (Runs out-of-the-box on Windows) | Python runtime or heavy dependencies |

## ✨ Features

- **🖱️ Comprehensive Click Attribution**:
  - Tracks **Left Clicks**, **Right Clicks**, and **Middle Clicks**.
  - Tracks all-time totals as well as daily counts (**Today's Clicks**).
- **🔌 Hardware Source Identification**:
  - Automatically identifies whether each click was generated by an external **USB Mouse** or the laptop's **Built-in Touchpad / Trackpad**.
  - Visual distribution split bar showing your USB vs. Touchpad usage ratio.
- **⚡ Ultra-Lightweight & Battery-Friendly**:
  - Event-driven using native Win32 `WM_INPUT`.
  - Zero polling loops, 0% CPU consumption when idle, and <15 MB RAM.
- **💾 Indestructible Shutdown-Safe Storage & Self-Healing**:
  - Counts stay intact across computer reboots, unexpected shutdowns, logoffs, and app restarts.
  - **Shutdown-Aware**: Listens to Win32 `WM_QUERYENDSESSION` / `WM_ENDSESSION` and acquires OS shutdown priority (`SetProcessShutdownParameters`) to flush data before Windows kills background processes.
  - **Atomic File Swapping**: Uses Win32 `ReplaceFile` to replace `%APPDATA%\CLICKO\stats.json` and maintain an automatic `stats.json.bak` backup.
  - **Self-Healing Multi-Tier Load**: If a hard power loss ever corrupts `stats.json`, CLICKO automatically restores from `stats.json.bak` or `stats.json.tmp`.
- **🚀 Windows Startup Support**:
  - Optional toggle to launch automatically with Windows (via `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
  - Starts silently in the background tray without stealing window focus.
- **🎨 Sleek Dark-Mode Dashboard**:
  - Real-time digital counters with live click flash feedback indicators.
  - Reset, save, and data folder quick actions.
- **🔔 Live System Tray Tooltip & Menu**:
  - Hover over the tray icon to view click totals at a glance.
  - Right-click menu with live counters, startup toggle, and dashboard shortcut.

## 🔬 How It Works: Technical Architecture

Standard Windows mouse hooks (`SetWindowsHookEx` with `WH_MOUSE_LL` used by tools like `pynput`) deliver `MSLLHOOKSTRUCT`, which strips out device origin information.

CLICKO solves this by implementing a **multi-stage hardware detection engine**:

```
[ Mouse / Touchpad Hardware ]
             │
             ▼
[ Windows HID / ACPI Driver ]
             │
             ▼
   WM_INPUT (Raw Input Sink)
             │
             ├──► RAWINPUTHEADER.hDevice (Device Handle)
             │          │
             │          ▼
             │   GetRawInputDeviceInfo (Device Interface Path)
             │          │
             │          ▼
             │   cfgmgr32.dll (Traverse PnP DevNode Parent Hierarchy)
             │          ├──► Parent starts with "USB\"  ==>  USB MOUSE
             │          └──► Parent is "ACPI\" / "I2C\" ==>  TOUCHPAD
             │
             └──► RAWMOUSE.usButtonFlags (Memory Aligned on x64)
                        │
                        ▼
             [ Interlocked Atomic Increment ]
                        │
                        ▼
             [ Debounced Atomic JSON Flush ]
```

1. **Win32 Raw Input Sink**:
   Registers a hidden message sink with `RIDEV_INPUTSINK` for `UsagePage = 0x01` (Generic Desktop) and `Usage = 0x02` (Mouse).
2. **PnP Device Tree Navigation (`cfgmgr32.dll`)**:
   Translates the device handle `hDevice` into an interface path (e.g. `\\?\HID#VID_30FA&PID_0400...`), converts it into a device instance ID, and queries `CM_Get_Parent` and `CM_Get_Device_ID`:
   - Devices whose parent node is on the `USB\` bus are classified as **USB Mouse**.
   - Devices whose parent node is on the `ACPI\` or `I2C\` bus (or contain hardware signatures such as `ELAN`, `SYNAPTICS`, `ALPS`, `MSFT`) are classified as **Touchpad**.
   - Synthetic gestures and touch injections (`MI_WP_SIGNATURE = 0xFF515700`) are mapped to **Touchpad**.
3. **High-Performance Caching**:
   Device classifications are cached in a thread-safe dictionary by device handle `IntPtr`, resulting in **O(1) microsecond lookup times** for every subsequent click.
4. **x64 Structure Alignment**:
   In native Win32 C/C++, `union { ULONG ulButtons; struct { USHORT usButtonFlags; ... } }` is 4-byte aligned. CLICKO implements explicit struct layout (`[FieldOffset(4)]`) ensuring 100% accurate button flag reads on both 64-bit and 32-bit systems.

## 📥 Installation & Running

### Option 1: Direct Download (Pre-Compiled Binary)
1. Download **`CLICKO.exe`** from this repository.
2. Run `CLICKO.exe`.
3. *(Optional)* Check **"Launch automatically on Windows Startup"** to keep it running every time your PC boots.

### Command-Line Arguments
```cmd
CLICKO.exe             :: Open the dashboard window and start monitoring
CLICKO.exe --minimized :: Launch directly to system tray (used for Windows Startup)
CLICKO.exe --reset     :: Reset all counters to 0
```

## 🛠️ Building from Source

No third-party SDKs, Visual Studio, or package managers (npm, pip, nuget) are required! CLICKO builds using the C# compiler (`csc.exe`) included with every modern Windows installation.

### 1-Click Build (Batch)
```cmd
build.bat
```

### 1-Click Build (PowerShell)
```powershell
.\build.ps1
```

### Manual Compiler Command
```powershell
& "C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe" `
    /nologo `
    /target:winexe `
    /optimize+ `
    /win32icon:icon.ico `
    /r:System.dll,System.Drawing.dll,System.Windows.Forms.dll,System.Web.Extensions.dll `
    /out:CLICKO.exe `
    src\Win32.cs `

    src\DashboardForm.cs `
    src\TrayContext.cs `
    src\Program.cs `
```

## 📁 Storage Format (`stats.json`)

Data is stored locally at `%APPDATA%\CLICKO\stats.json`:

```json
{
  "TotalLeft": 11420,
  "TotalRight": 2942,
  "TotalMiddle": 530,
  "UsbLeft": 9450,
  "UsbRight": 2210,
  "UsbMiddle": 520,
  "TouchpadLeft": 1970,
  "TouchpadRight": 732,
  "TouchpadMiddle": 10,
  "OtherLeft": 0,
  "OtherRight": 0,
  "OtherMiddle": 0,
  "TodayDate": "2026-10-20",
  "TodayLeft": 1420,
  "TodayRight": 310,
  "TodayMiddle": 45,
  "FirstStarted": "2026-10-20T12:00:00.0000000+05:30",
  "LastUpdated": "2026-10-20T18:05:00.0000000+05:30"
}
```

*Note: If you place a `stats.json` file in the same directory as `CLICKO.exe`, it will run in **portable mode** and save all data in that local folder.*
